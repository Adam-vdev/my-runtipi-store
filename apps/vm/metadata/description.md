# VM (QEMU)
ماكينة افتراضية جوه Docker (باستخدام [qemux/qemu](https://github.com/dockur/qemu)) تقدر تثبت فيها **أي نظام تشغيل** وتديره من المتصفح.

## المتطلبات
- المضيف لازم يدعم **KVM** ( وجود `/dev/kvm` ) — سيرفر hardware عادي، أو VM عليها Nested Virtualization مفعّلة. من غير KVM التشغيل هيبقى بطيء جداً (emulation).

## طريقة الاستخدام
- **ويب كونسول:** من صفحة التطبيق افتح الرابط على بورت 8006 (زرار Open) — من هناك تتابع تثبيت النظام واختار القرص والشبكة.
- **نظام التشغيل (BOOT):** اسم توزيعة جاهزة (مثل `ubuntu`, `mint`, `debian`, `fedora`, `arch`, `alpine`, `kali`) أو **رابط ISO مباشر**. ملاحظة: ويندوز يستخدم أحسن في تطبيق Windows (dockur/windows) لأن صورة qemu العادية مصممة للنظام اللي بيشتغل على x86.
- **RDP:** بعد ما تثبت النظام جوه الضيف وتشغّل بروتوكول RDP (ويندوز جاهز، لينكس ثبّت `xrdp`)، افتح برنامج Remote Desktop على `IP-السيرفر:<RDP Port>` (البورت اللي اخترته في فورم التثبيت، والافتراضي 3389).
- **حفظ البيانات:** القرص الافتراضي بيتحفظ في `${APP_DATA_DIR}/data/storage` — يفضل تعمل Backup للتطبيق قبل أي تعديلات كبيرة.
