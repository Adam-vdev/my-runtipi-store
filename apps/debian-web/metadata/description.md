# Debian Web
سطح مكتب Debian (XFCE) كامل بيشتغل من المتصفح عن طريق LinuxServer Webtop.

- الدخول: `https://<server-ip>:8590` (**لاحظ https مش http**)
- المتصفح هينبّهك إن الشهادة self-signed — اضغط "Advanced" ثم "Proceed" مرة واحدة بس
- البيانات محفوظة في مجلد `data/config` الخاص بالتطبيق جوه `app-data` بتاع runtipi
